# Photos Haut-Atlas — environnement de la Maison Bledi

À déposer dans ce dossier avec ces noms **exactement** :

| Fichier | Photo |
|---|---|
| `vallee-graminees.jpg` | **HERO** — Paysage panoramique : graminées dorées au premier plan, oliviers épars, montagne Atlas atmosphérique en arrière-plan (16:9 horizontal) |
| `riviere-heron.jpg` | Rivière/oued avec roches ocre-rouge, eau verte, aigrette blanche sur rocher central |
| `village-pise.jpg` | Village berbère en pisé/argile rouge sur flanc de colline avec terrasses cultivées |
| `cascade-oasis.jpg` | Cascade dans canyon, palmiers, eau émeraude, falaises rouges |
| `ecureuil-berberie.jpg` | Écureuil de Berbérie macro dans herbes sèches dorées |
| `agame-rocher.jpg` | Lézard agame bleu-vert sur rocher rouge, fond montagne |

## Format recommandé

- **JPEG** qualité 78-82 (paysages haute résolution)
- Résolution **2400×1350 minimum** pour `vallee-graminees.jpg` (utilisée en Hero plein écran)
- 1920×1080 minimum pour les autres
- Profil **sRGB**, optimisez via [Squoosh.app](https://squoosh.app) avant de pousser
