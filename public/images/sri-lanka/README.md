# Photos Opération Cartable Sri Lanka

À déposer dans ce dossier, avec ces noms **exactement** :

| Fichier | Photo |
|---|---|
| `groupe-classe.jpg` | Groupe d'enfants en uniforme + enseignantes + photographe accroupi devant, tous les bras levés en V de victoire |
| `groupe-cartables.jpg` | Enfants présentant les nouveaux cartables (Minnie, Minion, etc.) — moment de remise |
| `enfant-merci.jpg` | Gros plan : enfant + bénévole face-à-face, thumbs up, cartable "Quand je serai grande" |
| `enseignante-cadeau.jpg` | Enseignante souriante tenant un cartable noir + sari en cadeau |
| `medaille-merci.jpg` | Femme et bénévole montrant ensemble une médaille dorée (remerciement) |

## Format recommandé

- **JPEG**, qualité 75-80 (compromis poids/qualité pour photos terrain)
- Résolution **1920×1080 minimum**
- Profil **sRGB**

## Une fois les photos déposées

```bash
cd ~/Documents/Projets/association-partage
git add public/images/sri-lanka/
git commit -m "feat: photos Opération Cartable Sri Lanka"
git push origin main
```
